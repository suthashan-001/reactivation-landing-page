# IntakeAI Landing Page Agent Guide

## Project
Static landing page for IntakeAI.

## Repo layout
- `index.html`: page markup and copy
- `styles.css`: design system and responsive styles
- `script.js`: interactions/calculator/mobile nav/FAQ
- `README.md`: setup and publishing instructions

## Commands
- `python3 -m http.server 3000`
- `npx serve .`

## Engineering rules
- Keep it static.
- No framework unless explicitly requested.
- No fake testimonials.
- No fake logos.
- No compliance overclaims.
- All CTA links go to `https://cal.com/suthashan/15min`.
- Maintain accessibility.
- Maintain responsive design.
- Keep JS lightweight and dependency-free.

## Definition of done
- Page opens locally.
- No console errors.
- Mobile nav works.
- FAQ accordion works.
- ROI calculator works.
- All CTA links work.
- Lighthouse-style standards: strong contrast, responsive layout, semantic structure.
- Copy is specific to naturopathic patient reactivation, not generic AI.
